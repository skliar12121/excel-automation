# Excel Automation

## Задача заказчика

Объединить три Excel-файла от разных поставщиков в один.

## Требования

1. Сопоставить столбцы с разными названиями.
2. Определять одинаковые товары по артикулу.
3. Выбирать минимальную корректную цену.
4. Строки с отсутствующей ценой записывать в отчёт об ошибках.
5. Сохранять результат в файл result.xlsx.

## Результат

Excel-файл с двумя листами:
- Товары
- Ошибки## Как пользоваться программой

Программа автоматически объединяет прайс-листы поставщиков в формате Excel (`.xlsx`).

### Подготовка

1. Установите Python 3.12 или совместимую версию.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

   `python -m pip install -r requirements.txt`

### Запуск

1. Поместите файлы поставщиков в папку `input`.
2. Выполните команду:

   `python main.py`

3. Откройте созданный файл `output/result.xlsx`.

### Результат

Файл содержит два листа:

- **Товары** — уникальные артикулы с минимальной корректной ценой.
- **Ошибки** — строки с отсутствующими или некорректными данными, а также ошибки открытия файлов.

### Ограничения

- Поддерживаются файлы `.xlsx`.
- Для каждого товара необходимы артикул, название и положительная цена.
- Программа распознаёт заранее заданные варианты названий столбцов.
- Не выполняет автоматическую конвертацию валют.
- Не имеет графического интерфейса.

### Пример

Если поставщик №1 предлагает товар A101 за 1500 рублей, а поставщик №2 — за 1450 рублей, в итоговом файле останется цена 1450 рублей.
## Пример работы

**Задача:** объединить три Excel-прайс-листа поставщиков, удалить дубликаты по артикулу и выбрать минимальную корректную цену.

**Исходные данные:** три файла `.xlsx` с разными названиями столбцов. В некоторых строках отсутствуют цены.

**Результат:** программа создаёт `output/result.xlsx` с двумя листами:

- **Товары** — уникальные товары с минимальными ценами.
- **Ошибки** — строки, которые требуют проверки.

| Артикул | Название | Цена, руб. |
|---|---|---:|
| A101 | Мышь Logitech | 1450 |
| A102 | Клавиатура | 2400 |
| A103 | Монитор | 12500 |
| A104 | Наушники | 3200 |

В демонстрационном примере обработано 4 уникальных товара и обнаружена 1 строка с ошибкой.

Для самостоятельной проверки:

```bash
python create_test_data.py
python main.py
```

Пример показывает работу программы на искусственных данных. Реальные файлы заказчиков не публикуются.

## Проверка конфликтов

Если один артикул встречается у разных поставщиков с разными названиями, программа считает его спорным.

Такой артикул:
- исключается из листа «Товары»;
- фиксируется в отчёте об ошибках;
- отображается на листе «Конфликты» со всеми корректными исходными записями.

Лист «Конфликты» содержит:
- имя исходного файла;
- номер строки;
- артикул;
- название товара;
- цену.

Программа не определяет автоматически, какое название правильное. Решение принимает пользователь после проверки исходных данных.
